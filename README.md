# Max-Seal Premier

Create a premium, modern, multi-page website prototype for Max-Seal, a US-based engineered butterfly valve manufacturer and supplier.

This must not look like a generic AI-generated website, SaaS template, stock industrial template, or a copy of the current Max-Seal website. Do not replicate the current sitemap or current catalogue structure. Create a fresh, innovative, high-end industrial website experience that feels engineered, confident, clean, and premium.

Visual direction:

Hybrid style: dark, cinematic hero sections with clean white product and content pages

Modern industrial feel

Minimal but confident use of Pantone 2995 C as the brand accent

Premium typography

Strong spacing

Precision grid layouts

Classy, refined, non-stock visual style

No heavy graphics

No generic blue SaaS gradient look

No boring card-heavy AI template layout

Max-Seal positioning:
Max-Seal is not just an ordinary butterfly valve supplier. It is a performance-driven engineered valve partner and a one-stop source for many butterfly valve solutions. The website should lead with performance, quality, engineering trust, US-based support, and the message that Max-Seal is a stronger alternative to generic low-cost valve suppliers.

Core brand message to reflect:
“Not just ordinary butterfly valves. Built for performance. Many solutions. Zero compromise.”

Use this as inspiration, but do not copy it word for word everywhere. Write premium, natural content with simple words. Avoid jargon. Avoid robotic AI-style marketing copy.

Important content rule:
Do not use em dashes anywhere in the content.
Do not use generic AI phrases.
Do not overuse words like “seamless”, “unlock”, “elevate”, “cutting-edge”, “robust”, “next-generation”, or “transform”.
Keep the copy clear, premium, technical where needed, and human.

Build this as a real multi-page website prototype, not a single-page website.
